# Campaign milestone

The public /demo page is a fictional illustrative campaign walkthrough, authored in source. It performs no API calls, accepts no customer data, and keeps review state in the browser session. It is not recorded or live Meta output. The sample report includes that provenance.

Authenticated evidence drafts accept deliverable=campaign and require an audience, campaign angle, exactly three bounded captions, call to action and measurable experiment. Source-quote checks, workspace quotas, idempotency and paid-off defaults remain unchanged. Campaign content is rendered and exported in the owner-only report. Existing homepage requests continue to work.

Limitations: image interpretation, SAM masks, image quality scores and generated creatives are not implemented. Real structured Meta output remains unverified. A 500-token response ceiling remains in place to preserve credits; incomplete campaign output fails without retry. Do not enable unrestricted generation or treat successful schema validation as factual verification.
